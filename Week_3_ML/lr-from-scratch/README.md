# Linear Regression From Scratch (NumPy)

This project implements **Linear Regression from scratch using NumPy**, without using any machine learning libraries like scikit-learn.  
The goal is to understand **how a model learns mathematically** using Gradient Descent.

The model learns the relationship:

y = 2x + 1

and predicts outputs for new inputs.

---

## 📌 What This Project Does

- Builds Linear Regression from scratch
- Uses Mean Squared Error as the cost function
- Trains the model using Gradient Descent
- Predicts outputs for unseen inputs

---

## 🧠 Core Idea

The model uses the equation:

ŷ = wx + b  

Where:
- `w` is the weight (slope)
- `b` is the bias (intercept)

The goal is to find the **best values of `w` and `b`** that minimize prediction error.
